# Leilão Paroquial

    pip install -r requirements.txt
    python init_db.py      # opcional: o app.py também cria o banco ao iniciar
    python app.py          # abre em http://localhost:5000 (outros PCs: http://IP-DESTE-PC:5000)

Nome no cabeçalho e na promissória: `LEILAO_NOME="Festa de São José" python app.py`

Atalhos: Alt+1 Arrematação, Alt+2 Pessoas, Alt+3 Itens, F2 limpa, F4 cancela o último arremate, F8 promissória.
O Tailwind e a fonte vêm de CDN, então a máquina precisa de internet (ou baixe o Tailwind e sirva localmente).
